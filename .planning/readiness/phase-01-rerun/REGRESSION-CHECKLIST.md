# Regression Checklist

Use this checklist whenever a checkpoint artifact is reviewed, normalized, or translated into a new planning input.

## Canon

- [ ] `challenge` has not quietly retaken default-wrapper status
- [ ] `hosted` has not collapsed capability seam, owner model, and obligation profile
- [ ] recap/report, challenge-result, and true event-memory are still distinct
- [ ] memory surfaces remain layered rather than flattened
- [ ] `curated`, `reviewed`, and `unsupported` remain distinct
- [ ] support/access/service have not collapsed into pseudo-`premium`
- [ ] preserve-only and reversal-sensitive branches have not disappeared through prose cleanup

## Governance Docs

- [ ] root `AGENTS.md` is still general and slim, not lane residue
- [ ] `.planning/AGENTS.md` broad rules are not trapped in overly narrow sections
- [ ] examples remain subordinate to general rules
- [ ] duplicated policy has not drifted across governance docs
- [ ] slimming did not erase load-bearing distinctions

## Claim / Citation

- [ ] load-bearing planning/process artifacts use explicit claim typing where needed
- [ ] internal support is not presented as fresh external grounding
- [ ] support and basis markers match the actual work being done
- [ ] internal file-line citations were rechecked after surrounding docs moved
- [ ] external-comparative supplements are not treated as universal proof automatically

## Delegation / Orchestration

- [ ] substantial delegated edits were launched from an auditable baseline
- [ ] returned worker output received explicit disposition
- [ ] requested spawn settings were not confused with effective launch settings
- [ ] exploratory ambiguity-heavy work was delegated where that produced better depth

## Git / Checkpointing

- [ ] commits correspond to reasoning or scope boundaries, not mere elapsed time
- [ ] coherent reviewable units were checkpointed rather than allowed to sprawl
- [ ] one active change set did not turn back into multiple concern buckets
- [ ] rerun preparation is not proceeding on top of unrelated churn

## Phase 01 Rerun

- [ ] old `01-*` artifacts are still treated as historical input, not live steering
- [ ] already-corrected asymmetries have not been re-imported
- [ ] Milestone 01 scope has not widened through long-arc leakage
- [ ] `LONG-ARC.md` is constraining doctrine rather than exploding scope
- [ ] the rerun is not rediscovering mature-product doctrine that canon already settled
