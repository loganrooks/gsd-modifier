# Checkpoint 5 R5.16a Track B Propagation Cross-Vendor Prompt

Audit the current Track B candidate surfaces to determine whether the promoted review doctrine actually reaches the real review and replanning consumers.

This is a seam-specific gap-exposure and completeness-challenge audit. It is not a generic code review and it is not satisfied by rereading only the edited overlay files.

## Audit Stance

- Audit against the strongest justified pre-rerun quality standard, not against “better than before.”
- Treat the candidate bundle as potentially directionally right but still under-propagated.
- Look for places where the stronger review doctrine is stated upstream but flattened at handoff.
- Do not assume consensus-oriented language is harmless just because earlier sections became stronger.
- Be firm, specific, and scrutiny-resistant.
- Do not widen scope casually, but do name wider consequences if the current review-consumer chain clearly under-owns them.

## Questions

- Does the stronger doctrine survive from overlay candidate to real review consumer?
- Does the current review workflow still privilege `consensus concerns` or other soft flattening at the handoff surface?
- Does planner-side review consumption still allow justified lone criticism to be ignored too cheaply?
- Are “merely adequate” and “later audit risk” actually operationalized in the consumers, or only named in the producer?
- Does the current chain distinguish overlap/helpful consensus from false consensus?
- Is there any gap between overlay truth and live installed truth that makes the candidate patch set misleadingly complete?
- Which Track B gaps are truly local to review consumers, and which point to a wider post-verificationist / post-falsificationist lane?
- Are there important review-consumer or replanning surfaces missing from this lane's read set that would materially change the scope judgment if added?
- If the bundle stayed local, what likely quality gains or anomaly-accounting work would still be left on the table?

## Output

Write a review artifact with:

- `Verdict`
- `Blocking Propagation Gaps`
- `Local But Important Gaps`
- `Signals That The Problem May Already Be Wider`
- `What Is Already Strong`
- `What Must Change Before Track B Can Count As Closure-Ready`
- `What Can Remain Local`
- `Change Summary`

Findings should be ordered by severity and cite concrete file lines.
