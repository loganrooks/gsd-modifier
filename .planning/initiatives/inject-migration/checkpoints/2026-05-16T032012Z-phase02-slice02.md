### Per-kind idempotency semantics (codified in tests)

- **section_insert_after / step_insert_after / include_add / block_replace** (create-ops): marker present + body matches source → skip; present + differs → fatal (marker_key_conflict — same key bound by different operation OR manual edit inside markers)
- **section_replace** (update-op): marker present + matches → skip; present + differs → REPLACE (the operation's purpose); marker absent → fatal (requires prior section_insert_after)
- **step_remove** (replace-with-sentinel): marker present + contains step_removed sentinel → skip; present + wrong sentinel → fatal; absent → apply (replace step block with sentinel marker)
- **include_remove** (delete-op): marker absent → skip (already removed; idempotent inverse of include_add); present + body contains line → remove; present + body lacks line → fatal
