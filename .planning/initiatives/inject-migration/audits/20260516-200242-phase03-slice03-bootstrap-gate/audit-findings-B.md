## Convergent risks

F1, F2, and F4 all point at the same underlying weakness: **the "known stale baseline" label has been doing more rhetorical work each iteration than the underlying evidence justifies, and now extends to cover both a shape change (F1) and the absorption of a new inject-caused failure mode (F2/F4)**. The label was accurate at Phase 2 boundary. At Phase 3 Slice 2 it absorbed seed-audit without operator refresh. At Phase 3 Slice 3 it would absorb transition-uplift plus implicitly normalize the runtime_visibility.py downstream consequence if accepted as written. Two more iterations of the same pattern and the operator loses the ability to detect a real regression behind the baseline frame. The single concrete fix: debriefs and STATE.md updates must explicitly enumerate baseline members each iteration, and any new member triggers either a STATE.md update (one bullet) or a Plan-mediated scope expansion. Both are cheap; the current implicit absorption is what costs.
