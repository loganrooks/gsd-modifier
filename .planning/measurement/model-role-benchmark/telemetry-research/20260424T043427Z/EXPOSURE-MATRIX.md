## Cross-Surface Implications

- Requested state and effective state must be separate. Config/docs expose requested/default behavior; local runtime logs and API responses expose observed/effective behavior.
- Runtime response items are not provider model calls. The architecture resolves this as a generic `runtime_response_items` concept with explicit correlation status.
- Cost needs evidence modes. API-equivalent estimates, provider-reported per-request costs, provider aggregate costs, subscription/quota burn, and manual costs are distinct.
- OTel is fixture-gated. Docs prove configuration and conventions; they do not prove emitted payloads in this environment.
- Claude thinking/facets/session-meta are substitute or aggregate signals. They must not become reasoning-token or quality truth.
- JSONL/raw artifacts remain durable evidence. SQLite is a rebuildable cache with registry and source-set hashes.
