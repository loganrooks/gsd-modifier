# Opinion Mining Seeds

Seed files list curated public URLs for extraction.

Use JSONL. Each row must include:

```json
{"source_id":"reddit-codex-001","platform":"reddit","url":"https://example.com/thread","query":"site:reddit.com/r/codex \"GPT-5.5\" \"usage\"","claim_tags":["usage"],"collection_caveat":"Search-indexed sample; not representative."}
```

Do not store credentials, cookies, or private URLs here.
