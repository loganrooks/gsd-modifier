## Carriage Criteria

| Criterion | Working test in this review |
| --- | --- |
| Diagnostic precision | Does the move distinguish materially different cases or carriers? |
| Burden / authority visibility | Does it expose who or what actually governs? |
| Intervention routing | Does it improve how the next move is chosen? |
| Reproducibility by later reviewers | Can a later reviewer apply it without heroic reconstruction? |
| Reduced dependence on unusually strong operator prose | Does it survive weaker operators and ordinary rereads? |
| Indirect-carrier legibility | Does it make hidden or local carriers more answerable? |
| Openness that redistributes defaults | Does it alter default closure, not only postpone it? |
| Technical or procedural implementability | Can it be expressed as a bounded local proposal or clean stress test? |
| Improved attainable-outcome quality | Does it plausibly improve the next attainable artifact, not only its vocabulary? |

- [s:r:i] Decision rule used here:
- `ready_for_local_proposal` means the gain is already concrete, bounded, and proposal-shapeable without needing a broader doctrine rewrite
- `ready_for_bounded_stress_test` means the gain is plausible but still needs one discriminating live test
- `reviewer_register_only` means the gain is mostly diagnostic compression or reviewer prose support
- `not_earned_on_this_evidence` means current evidence does not justify even bounded operationalization pressure
