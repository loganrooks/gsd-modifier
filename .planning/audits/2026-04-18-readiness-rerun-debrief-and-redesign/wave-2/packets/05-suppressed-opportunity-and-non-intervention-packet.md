## Use Notes

- [g:r:i] Separate at least these classes in the register:
  - `visible but unchosen stronger move`
  - `partially landed but under-carried move`
  - `bounded experiment now warranted`
  - `still-unearned stronger move`
  - `program-shape alternative`
- [g:r:i] Explicit prior disposition is not enough by itself. The lane should ask whether the burden of proof those non-interventions carried would still survive after the accepted Wave-1 returns.
- [g:r:i] Risk or size language is not self-justifying. If a stronger move is rejected because it is `too large`, the lane must name the execution-capacity model and the mitigation path that still failed to make it worth doing.
