   - stop condition:

   - why here:

### Slice 2: Consumer And Runtime Discrimination

3. `Named-consumer doctrine propagation slice`
   - target surfaces:
     - `review.md`
     - `planner-reviews.md`
     - `plan-phase` read-path carry
   - why before doctrine edits:
     - accepted Wave-2 carry says the live miss is downstream carrier undercarry more than baseline doctrine weakness
   - output class:
     - bounded local proposal, likely then bounded patch
   - stop condition:
     - consumer path is concretely specified and remains narrow

4. `Runtime-authority / materialization discriminator`
   - accepted current base:
     - the bounded drift probe already leans toward bounded `Proposal F` follow-through
   - next smallest move:
     - throwaway-worktree reinstall classification pass to separate expected substitution from unexplained drift
   - why here:
     - this is the sharpest discriminator between staying with bounded prerequisite carry and escalating toward a stronger harness branch
   - output class:
     - bounded probe artifact
   - stop condition:
     - differences are classified as `expected substitution`, `installer/profile mutation`, or `unexplained drift`

### Slice 3: Program-Honesty Rules

5. `Minimum rerun-readiness set recomputation`
   - why after slices 1-2:
     - the rerun floor should be recomputed against the freshest accepted closure and runtime evidence, not against stale assumptions
   - output class:
     - local proposal / state artifact
   - stop condition:
     - explicit rerun floor with cited carry and explicit remainder list

6. `Brake-exit rule authoring`
   - why now:
     - lane-06 made this a hard prerequisite, not later philosophy
   - output class:
     - proposal artifact first, then possible narrow doctrine patch
   - stop condition:
     - explicit release conditions from recursive inward motion are named

7. `Preserve-only activation-trigger doctrine`
   - why paired with brake-exit:
     - both are the anti-permanent-deferral side of the accepted program
   - output class:
     - proposal artifact first
   - stop condition:
