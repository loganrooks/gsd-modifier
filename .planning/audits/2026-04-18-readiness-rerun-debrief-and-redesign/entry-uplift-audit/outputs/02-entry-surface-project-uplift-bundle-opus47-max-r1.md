### 2. Detection signals in `39` smuggle threshold language back as deficit comparison

- [e:c+i] Signals in `39` include "thin or older governing-doc posture," "materially older than current repo doctrine," and "clearly outside current repo posture." Source: [39:73-76](../../intervention-proposals/39-project-uplift-workflow-proposal.md:73).

"Thin" and "older" are threshold comparisons against an implicit bar. A stronger positive form names what the comparison is over: a doctrine fingerprint per carrier (version or content hash) plus an explicit delta list ("carrier X fingerprint differs from current repo-local version at sections A, B"). Without a fingerprint abstraction, the first slice ships with re-implemented prose comparison each time it runs.

## What The Workflow Should Own

- [d:r:i] Posture detection as structured evidence, not prose pattern-matching. The workflow reads a doctrine fingerprint per carrier (version marker or content hash) plus a small explicit delta list, and writes both into `UPLIFT-REPORT.md` and the persistent manifest.
- [d:r:i] Composed evidence from specialist owners without reimplementing them. The workflow consumes `update` install-truth ([update.md:244-246](/home/rookslog/workspace/projects/prix-guesser/.codex/get-shit-done/workflows/update.md:244)), `health` integrity ([health.md:27](/home/rookslog/workspace/projects/prix-guesser/.codex/get-shit-done/workflows/health.md:27)), `runtime_visibility.py` output, `manifest_install_coherence.py` output, and the project's own state files. It never invokes the installer, never repairs, never runs the roadmapper.
- [d:r:i] Classification persistence. Each pass records one of `vanilla` / `aged-bespoke` / `cross-runtime` / `upstream-template-drift` into `UPLIFT-STATE.md` so later widening families can read continuity, not retro-fabricate it.
- [d:r:i] Compact per-carrier refresh with explicit scope flags. The first slice exposes only the smallest high-yield subset (carriers that are absent rather than bespoke) as installable from the workflow; bespoke-content refreshes stay with later families.
- [d:r:i] Durable before/after memory with structural diff, not only prose. `UPLIFT-REPORT.md` carries an explicit carrier-state-before table, carrier-state-after table, and a delta list that a consumer surface or later audit can read without prose parsing.
- [d:r:i] Thin doctrine manifest as a first-slice output. The manifest is the only handle that lets `progress` and `resume-project` consume posture vintage without prose parsing. Keeping it thin (carrier-name → version marker, no content) makes it land in first slice without scope creep.
- [d:r:i] One routed-recommendation hook in `progress` — a single read-only line, no absorption. That is the minimum that brings the consumer-side carry online in the first slice.
- [d:r:i] A detect-only run mode as the default invocation. Refresh becomes an explicit flag.
- [d:r:i] Self-scan with `scan_threshold_language.py` on any generated `UPLIFT-REPORT.md` content before finalizing, so the workflow does not become a new regression surface for threshold language.
