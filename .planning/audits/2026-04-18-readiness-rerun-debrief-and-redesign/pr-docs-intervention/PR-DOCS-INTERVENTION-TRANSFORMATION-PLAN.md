## Governing Split

### 1. Stable Reference Layer

- [d:r:i] Preserve the submitted PR-doc family in the role it is strongest at:
  - inventory and roster truth
  - contributor orientation
  - command reference
  - role-card reference
  - broad architecture vocabulary
- [d:r:i] This layer should stay relatively stable and readable. It should not become the place where every repo-local intervention tactic, local drift note, or leverage ranking gets embedded.

### 2. Intervention Companion Layer

- [d:r:i] Build and maintain a distinct companion layer that carries:
  - declared versus effective authority
  - runtime materialization order
  - leverage-ranked intervention surfaces
  - local/current-upstream/frozen-snapshot status distinctions
  - route-to-surface guidance for future modifiers
- [d:r:i] This layer is where stronger repo-local intervention planning belongs.

### 3. Governance / Verification Layer

- [d:r:i] Port the parity-guard discipline into repo-local tooling and doc maintenance.
- [d:r:i] The strongest reuse from the PR docs is the inventory/parity pattern, not the literal snapshot as a sovereign truth object.

- [d:r:i] No assumption that more prose alone solves intervention carry without governance and verification support.
