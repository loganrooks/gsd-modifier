# Propagation Registry System Cross-Vendor Inheritance

## Purpose

- [g:r:i] This note records how the cross-vendor reread of the propagation-registry system is inherited locally.
- [g:r:i] The governing question is not whether a machine-readable registry belongs in this family at all. The governing question is how the registry family should be split so maintained rosters, declared contracts, generated evidence, semantic mapping, and operator control stop blurring into one compressed surface.
- [d:r:i] For this lane, Opus carries the widening lead. The local GPT review remains a corroborating contrast surface where it sharpens the same direction or warns against re-blending the layers.
