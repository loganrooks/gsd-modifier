This chunk asks the governance question that inevitably follows a central registry: how much versioning does that surface need? The note avoids both archive ritual and silent drift. Full pinning for every wording refinement is too heavy. No version awareness at all is too loose, because later readers will quietly interpret old exemplars through new meanings. The proposed answer is thresholded versioning. Small editorial clarifications can update the current definition quietly. Material changes in scope, exclusion, status, or intended function should create a new revision marker. The relevant test is not whether text changed, but whether meaning changed enough to alter rereading.

That criterion has an immediate consequence for exemplars. They should only pin to a specific definition version when a later change would materially alter how the exemplar is understood. This is a good proportional rule because it preserves interpretive lineage where it matters while avoiding ceremonial pinning where it does not. The note is consistently trying to keep traceability answerable to actual rereading consequences rather than to archive aesthetics.

The next section turns to authority. If versioning is thresholded, then someone has to decide whether a change is merely editorial or materially interpretive. The note again refuses one blunt answer. A single local editor is enough for clearly minor changes in low-force blocks. But suspected material changes should be flagged rather than silently absorbed, and higher-force blocks or changes with clear rereading consequences should receive at least one rival-reader or steward check. The threshold rises with downstream force, likelihood of rereading change, and the chance that misclassification would distort later judgment.

This is another place where the note's proportional method shows its strength. The key question is not abstractly who has final authority. It is what is at stake if this edit is misclassified. A system that requires collective review for every minor wording update will seize up. A system that lets `clarification` silently cover material semantic shift will drift while imagining itself stable. The staged answer is therefore more exact than either central control or total local discretion.

This chunk therefore gives the definition architecture a rereading ethic. Version where meaning changes, not wherever text changes. Pin exemplars where interpretation would otherwise drift. Escalate materiality review in proportion to force and consequence. If I extend the point, I would say that the slice is trying to preserve historical intelligibility without converting the registry into a ritual archive: enough versioning to keep old uses legible, enough local discretion to keep the system workable, and enough review to stop `editorial` from becoming the quiet name for semantic power. That phrasing is mine, but it follows the sequence closely.

# Operational Translation

## Thresholded Versioning

Textual pressure: exhaustive pinning is too heavy, but zero version awareness permits silent semantic drift.
Interpretive translation: versioning should respond to material interpretive change, not to every textual edit.
Audit-design implication: create revision markers only when scope, exclusion, status, or intended function shifts enough to affect later interpretation.
Scope: definition lineage and registry maintenance.
Confidence: high.

## Materiality By Rereading Consequence

Textual pressure: the key question is whether an older use would be read differently after a change.
Interpretive translation: materiality is an interpretive threshold, not a textual one.
Audit-design implication: judge revision materiality by whether earlier exemplars, logs, or decisions would be reread differently under the new wording.
Scope: revision assessment and lineage control.
Confidence: high.

## Selective Exemplar Pinning

Textual pressure: not every definition refinement justifies pinning every use to a version.
Interpretive translation: exemplars need version pinning only at materially interpretive change points.
Audit-design implication: pin exemplar references to definition versions when later changes would otherwise distort their meaning; treat purely editorial changes more lightly.
Scope: exemplar traceability and archive overhead management.
Confidence: high.

## Proportional Materiality Authority

Textual pressure: deciding what counts as material itself shapes future rereading.
Interpretive translation: authority for materiality decisions should rise with downstream force and misclassification risk.
Audit-design implication: allow local classification of clearly minor changes, require flags for suspected material changes, and use rival-reader or steward checks for high-force or ambiguous cases.
Scope: change governance and definition stewardship.
Confidence: high.
