# Docs Audit

This subtree holds bounded lanes about documentation carry, inheritance, and transformation for the submitted upstream docs PR and related onboarding/intervention surfaces.

Use this subtree when the question is not general readiness rerun design, but specifically:

- what the docs corpus carries
- what it still flattens or hides
- how it should be challenged
- how it should be inherited or transformed

Keep these lanes narrow. They are not broad repo audits and not broad rerun-program reconsideration by default.
