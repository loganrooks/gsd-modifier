## Terms

### Rerun Floor

- [d:r:i] Plain meaning:
  - the minimum real set of things that still must be true before we can honestly start the fresh Phase 01 rerun
- [d:r:i] What it does not mean:
  - the ideal final state
  - every improvement we might still want
  - a perfect harness
- [e:c+i] In the current workspace, the recomputed floor is the narrower remaining set after the parity/materialization seam was already reduced as far as current evidence justifies. ### Brake-Exit Rule

- [d:r:i] Plain meaning:
  - the rule for when we stop more prep recursion and release into the next real path instead of protecting ourselves by preparing forever
- [e:c+i] More exactly, it says to stop inward motion when the active blocker has already been turned into executed work, explicit remainder, or a still-live discriminating test, and the next prep move would no longer materially increase intervention yield.
