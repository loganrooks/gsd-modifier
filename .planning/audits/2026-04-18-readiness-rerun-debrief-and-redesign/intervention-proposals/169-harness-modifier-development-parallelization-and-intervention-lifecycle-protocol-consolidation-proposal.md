- [d:r:i] Define what work is safe to do while an external review lane runs.

- [d:r:i] Define when a lane should be rechecked rather than waiting idly.
- [d:r:i] Define how frozen-basis / read-set / authority surfaces should be named locally on the face of a lane.

### 2. Composition-Keeping Delegation

- [d:r:i] Define when bounded sub-agents are earned inside harness-modifier development.
- [d:r:i] Keep the parent thread as composition owner for:
  - disposition
  - governance carry
  - propagation carry
  - checkpoint boundaries
- [d:r:i] Keep this about development work, not harness-in-action workflow fan-out.

### 3. Intervention Lifecycle Loop

- [d:r:i] Consolidate the stronger repeated loop into explicit protocol:
  - plan intervention
  - name intended effects and propagation obligations
  - land slice
  - monitor actual effects
  - audit mismatches / under-carry
  - revise protocol or route later follow-through
- [d:r:i] Keep this loop visible across proposals, implementations, audits, propagation refreshes, and governance carry rather than letting it survive only as good operator habit.
