## Rule

- [g:r:i] Any recommendation that rejects a stronger move on `size`, `risk`, `too much`, or `not now at this breadth` grounds must explicitly say:
  1. which execution model it is actually using
  2. what recent enacted-budget evidence supports or weakens that model
  3. whether the constraint is:
     - operator attention
     - reviewability
     - rollback cost
     - upstream-ownership boundary
     - or something else
  4. what narrower sequence or checkpoint boundary would preserve more intervention yield

## Reopen Conditions

- [g:r:i] Reopen the execution-capacity model when any of these happen:
  1. repeated meta-prep consumes the same or more budget than the stronger bounded intervention it is postponing
  2. actual launch-truth / checkpoint discipline shows the operator can carry a stronger bounded tranche than prior conservative language assumed
  3. reviewability or rollback boundaries fail in practice and the current model was over-optimistic
  4. a proposed move quietly assumes upstream `gsd` ownership or a larger environmental split than the charter allows

## Disposition Set

- [g:r:i] Allowed explicit dispositions:
  - `preserve as-is`
  - `preserve with tension flag`
  - `revise downward for this tranche`
  - `revise upward for this tranche`
  - `reopen as unresolved`
