# Long-Horizon Field Mapping Cross-Vendor Spec

## Framing

- [g:r:i] Audit the harness for long-horizon carry, horizon-tension handling, optionality preservation, and positive self-overcoming pressure.
- [g:r:i] The governing task is to map the whole field first. Do not optimize for identifying only a few “top” gaps before the field itself is visible.
- [g:r:i] Do not answer in threshold terms such as `adequate`, `sufficient`, `good enough`, `passes`, `ready`, `truly load-bearing`, or similar binary/gate language unless you are explicitly naming a literal operational gate.
- [g:r:i] The questions are:
  - where is long-horizon carry already strong
  - where does it weaken, flatten, or disappear later
  - what cross-horizon tensions are not yet structurally carried
  - what positive strength-building / self-overcoming surfaces are still missing
  - how do these pressures relate, cluster, propagate, or conflict

## Primary Questions

1. How should the full field of long-horizon lifecycle pressures be mapped across the current harness?
2. Which claims in the current gap register are overstated, under-articulated, or still too diffuse?
3. Which additional surfaces or pressure families are missing from the current register?
4. How do the mapped pressures relate?
   - which reinforce each other
   - which conflict
   - which are upstream/downstream of others
   - which create multi-surface propagation if changed
5. What positive strengthening opportunities become visible only when the whole field is mapped?
6. Is the current framing of optionality, multi-horizon tension, and harness self-overcoming strong enough, or is it still too negative, too local, or too vague?

## Required Output Shape

Use these exact section headings:

1. `Where Long-Horizon Carry Is Already Strong`
2. `Lifecycle Weakening And Carry Loss`
3. `Cross-Horizon Tensions`
4. `Positive Strength-Building Surfaces`
5. `Field Relations And Propagation`
6. `Gaps Or Overclaims In The Current Register`
7. `Additional Surfaces To Add`
8. `What This Changes About The Harness Improvement Program`

Inside section `8`, separate:
- `Map First`
- `Bounded Follow-Through Candidates`
- `Do Not Collapse Yet`

## Review Discipline

- [d:r:i] Challenge the register from the primary surfaces. Do not merely restate it.
- [d:r:i] Be concrete about where the packet supports each judgment.
- [d:r:i] If you think a claimed gap is weak or overstated, say what narrower or stronger formulation should replace it.
- [d:r:i] If you add new surfaces, explain what they carry and why they matter to the field as a whole.
- [d:r:i] If you name intervention families, do so after mapping; do not let early intervention enthusiasm erase terrain disclosure.
