# Code Of Conduct

This repo is developed for careful internal use and collaborative improvement.

Working expectations:
- keep reasoning and edits auditable
- prefer direct, respectful technical disagreement over ambiguity
- do not hide uncertainty, breakage, or drift
- preserve a clean distinction between shipped surfaces, support tooling, and historical carry

This file exists primarily because some shipped workflow/agent surfaces expect a repo-level code-of-conduct target.
